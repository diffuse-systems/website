Requirement

2.36

glibc floor

Built in a Debian bookworm container, so the packages run on Debian 12 and newer and Ubuntu 22.04 LTS and newer. Building on current stable would exclude every LTS in service.

Requirement

4 GB

Memory, not a card

A quantised model of that size runs on an ordinary workstation. A GPU makes generation faster and lets one machine hold more; it is not required.

Requirement

1

A licence file

Issued to your organisation and installed with one command. Trials are thirty days on three machines, running exactly what a paying customer runs.

Installing

Two commands on the coordinator, two on each machine that computes. No script to run, nothing fetched at install, and nothing downloaded when a node is given a model.
