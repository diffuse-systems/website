Installation

Deux commandes sur le coordinateur.

Terminal
curl -fsSLO https://github.com/diffuse-systems/releases/releases/latest/download/diffuse-coordinator_amd64.deb
curl -fsSLO https://github.com/diffuse-systems/releases/releases/latest/download/SHA256SUMS
sha256sum --ignore-missing -c SHA256SUMS

sudo apt install ./diffuse-coordinator_amd64.deb
sudo diffuse-coordinator licence set ./licence

Aucun script à lancer, rien n’est téléchargé à l’installation. Les liens mènent toujours à la dernière version et ne portent pas de numéro.

Prérequis

Une machine Linux et une licence.

Une machine Linux

Debian, Ubuntu ou tout Linux 64 bits récent.

Tout ce dont elle a besoin est dans le paquet, Python compris. Avec une carte NVIDIA, vos modèles tournent sur le GPU sans aucun réglage.

Une licence

Un fichier signé, installé en une commande.

Commencez par un essai de trente jours sur trois machines, avec exactement le logiciel de nos clients.

Obtenir une licence

Avant l’installation

Préparez le poste.

Quel matériel prévoir ?

N’importe quelle machine Linux 64 bits. Un poste fait tourner seul un modèle quantifié ; un serveur avec une carte NVIDIA sert de plus grands modèles à beaucoup de personnes à la fois.

Comment vérifier les fichiers ?

Placez SHA256SUMS dans le même dossier que les paquets correspondants. Sous Linux, lancez sha256sum --ignore-missing -c SHA256SUMS et vérifiez le résultat pour chaque fichier attendu.

Où trouver la licence ?

L’équipe délivre un fichier signé pour votre organisation. Pour un pilote, demandez une licence d’essai de trente jours couvrant trois machines. Demander l’essai

Et pour les GPU NVIDIA ?

Installez l’agent GPU avec ses paquets d’exécution CUDA : vLLM et llama-server, construits pour CUDA 13, font tourner vos modèles sur la carte dès le premier démarrage. Voir la version publiée
