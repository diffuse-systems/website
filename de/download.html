Installation

Zwei Befehle auf dem Koordinator.

Shell
curl -fsSLO https://github.com/diffuse-systems/releases/releases/latest/download/diffuse-coordinator_amd64.deb
curl -fsSLO https://github.com/diffuse-systems/releases/releases/latest/download/SHA256SUMS
sha256sum --ignore-missing -c SHA256SUMS

sudo apt install ./diffuse-coordinator_amd64.deb
sudo diffuse-coordinator licence set ./licence

Kein Skript auszuführen und nichts wird bei der Installation nachgeladen. Die Links zeigen immer auf die neueste Version und tragen keine Versionsnummer.

Voraussetzungen

Eine Linux-Maschine und eine Lizenz.

Eine Linux-Maschine

Debian, Ubuntu oder jedes aktuelle 64-Bit-Linux.

Alles Nötige steckt im Paket, sogar das eigene Python. Mit einer NVIDIA-Karte laufen Ihre Modelle ohne Einrichtung auf der GPU.

Eine Lizenz

Eine signierte Datei, installiert mit einem Befehl.

Starten Sie mit 90 Tagen Testversion auf drei Maschinen, mit genau der Software, die unsere Kunden betreiben.

Lizenz anfordern

Vor der Installation

Die Maschine vorbereiten.

Welche Hardware brauche ich?

Jede 64-Bit-Linux-Maschine. Eine Workstation betreibt ein quantisiertes Modell allein; ein Server mit NVIDIA-Karte bedient größere Modelle für viele Menschen gleichzeitig.

Wie prüfe ich die Dateien?

Legen Sie SHA256SUMS neben die passenden Pakete. Unter Linux ausführen: sha256sum --ignore-missing -c SHA256SUMS und das Ergebnis für jede erwartete Datei prüfen.

Woher bekomme ich eine Lizenz?

Das Team stellt eine signierte Datei für Ihre Organisation aus. Für ein Pilotprojekt fordern Sie eine 90-Tage-Testlizenz für drei Maschinen an. Testversion anfordern

Und NVIDIA-GPUs?

Installieren Sie den GPU-Knotenagenten mit seinen CUDA-Laufzeitpaketen: Diffuse, gebaut für CUDA 13, betreibt Ihre Modelle ab dem ersten Start auf der Karte. Zur Version
