Technical review

Four questions before rollout.

Machine identity

A network address can change.

Machines authenticate each other with certificates. The operator can revoke an identity.

Application access

An application only needs access to its own model.

Set the scope and expiry of an API key. A reporting service can lose access on the agreed date.

Administrative trail

A review asks you to reconstruct a change.

The audit trail records the actor, administrative actions and refusals. Prompt and response content stays out of the audit log.

Isolated network

The deployment site operates offline.

Import models locally and install the signed licence file. The product checks the licence on site.
