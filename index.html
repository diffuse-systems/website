What it is

A data centre from the machines you own.

01 · Install

One package per Linux machine

Install the coordinator on one machine and the agent on the others. Each machine joins in one command, with its own certificate.

02 · Pool

Your machines become one cluster

Diffuse measures every machine and places each model where it runs best: on a workstation, on a GPU server, or across several machines at once.

03 · Use

Your teams use it like OpenAI

Applications, coding assistants and a chat interface call an OpenAI-compatible API on your network. Fine-tune and distil on the same machines.

Secure end to end

Sensitive data, without fear.

Encrypted between every machine

Mutual TLS on every connection.

Each machine proves who it is with a certificate from your own authority, and everything between machines travels encrypted.

Access you decide

Accounts, roles and scoped API keys.

Give each application exactly the models it needs, for as long as it needs them, and revoke access in one command.

A trail for every action

Who deployed, who called, who changed what.

The audit trail records every administrative action and every request, and exports cleanly for your auditors. Prompts and answers stay out of it.

Nothing leaves your network

No telemetry, no cloud, no call home.

Models are imported locally and the licence is checked on site, so the whole platform runs even on an isolated network.
