Installing

Two commands on the coordinator.

Shell
curl -fsSLO https://github.com/diffuse-systems/releases/releases/latest/download/diffuse-coordinator_amd64.deb
curl -fsSLO https://github.com/diffuse-systems/releases/releases/latest/download/SHA256SUMS
sha256sum --ignore-missing -c SHA256SUMS

sudo apt install ./diffuse-coordinator_amd64.deb
sudo diffuse-coordinator licence set ./licence

No script to run and nothing fetched at install. The links always point at the newest release and carry no version.

What hardware do I need?

Any 64-bit Linux machine. A workstation runs a quantised model on its own; a server with an NVIDIA card serves larger models to many people at once.

How do I verify the files?

Place SHA256SUMS alongside the matching packages. On Linux, run sha256sum --ignore-missing -c SHA256SUMS and check the result for every expected file.

Where do I get a licence?

The team issues a signed file for your organisation. For a pilot, request a 90-day trial licence covering three machines. Request a trial

What about NVIDIA GPUs?

Install the GPU node agent with its CUDA runtime packages: Diffuse, built for CUDA 13, runs your models on the card from the first start. See the release
