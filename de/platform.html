Diffuse Enterprise

Eine API für Ihren Maschinenpark.

Ihre Anwendung spricht bereits das OpenAI-Format. Geben Sie ihr eine Adresse in Ihrem Netz und einen Schlüssel, beschränkt auf das Modell Ihres Teams.

Lebenszyklus eines Modells

Von der ersten Anfrage zum spezialisierten Modell.

Bereitstellen

Eine Anwendung anbinden

Laden Sie das Modell auf eine Maschine, wenn es passt. Ein größeres Modell verteilen Sie mit seinen Schichten auf mehrere Knoten, bei gleichem Endpunkt für die Anwendung.

Modellbereitstellung
Anpassen

Ihm Ihre Fachsprache beibringen

Trainieren Sie einen LoRA-Adapter mit Beispielen aus Ihrem Fachgebiet. Der Zusammenhang zwischen Korpus, Basismodell und Adapter bleibt bei der Evaluation sichtbar.

Fine-Tuning
Destillieren

Auf eine kleinere Maschine zielen

Lassen Sie ein größeres Modell ein kleineres lehren. Bewerten Sie beide mit denselben Fragen, bevor Sie das Modell für Ihre Nutzer wechseln.

Destillation

Gemessen auf einer echten Karte

Eine NVIDIA-Karte, mehrere Menschen.

Qwen3-32B · Q4_K_M

37,7 Tokens pro Sekunde für eine Person.

101,9 Tokens pro Sekunde insgesamt für sechzehn gleichzeitige Clients, bereitgestellt von Diffuse auf der Karte.

Qwen3.8-27B · Q4_K_M

41,3 Tokens pro Sekunde für eine Person.

131,9 Tokens pro Sekunde insgesamt für sechzehn gleichzeitige Clients, auf derselben Karte.

Qwen3-14B · bf16

148,1 Tokens pro Sekunde insgesamt für sechzehn Clients.

Bereitgestellt von Diffuse auf derselben Karte, jede Anfrage beantwortet.

Bedingungen

Eine NVIDIA L40 mit 48 GB, am 25. November 2026.

Diffuse Enterprise 1.6.0, installiert mit einem Befehl, 256 Tokens pro Antwort, Reasoning aus, ein Kontext von 16.384. Auf einem Server mit 12 vCPU ohne GPU antwortete Qwen3-14B mit 6,5 Tokens pro Sekunde.
